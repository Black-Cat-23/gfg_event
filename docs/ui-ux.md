# RecruitQuest — UI/UX Design

## 1. Visual Language
- **Tokens**:
  - `--bg`: `#FAFAFA`
  - `--surface`: `#FFFFFF`
  - `--ink`: `#111827`
  - `--muted`: `#6B7280`
  - `--accent`: `#4F46E5` (Indigo)
  - `--accent-soft`: `rgba(79,70,229,0.1)`
  - `--danger`: `#DC2626`
  - `--success`: `#16A34A`
  - `--border`: `#E5E7EB`

- **Typography**:
  - Timer Hero: 56–72px / bold
  - Title: 24px / 600
  - Body: 17–19px
  - Control: 16px
  - Meta: 13–14px

## 2. Key UI Screens
- Landing (Create / Join Team)
- Team Code Show-Once (with copy button)
- Lobby ("Waiting for organizer...", "Next up" chip, countdown interstitial)
- Quiz Shell (Question in short lines, option rows, immediate lock visual feedback)
- Market Shell (Scenario card, Buy/Sell/Hold controls per company, bottom portfolio bar)
- Admin Dashboard (Passcode door, event controls, roster, score overrides, projector view, JSON editor)
